# 个人公共规则

- 默认用中文交流；围绕当前问题推进，不因工具多而扩大任务。
- 讲解知识时，从背景和问题出发，解释为什么需要某种方法，再用具体例子推导；避免只罗列结论。
- 用户要求同步思路或只读检查时，先讨论，不把它当成修改配置的授权。
- 明确区分已验证、推断和待验证；文件已写入不等于软件已经加载。

## 公共资产

个人公共库位于 D:/AgentKit。规则源文件在 rules/common.md，公共 Skills 在 skills，知识入口在 knowledge/INDEX.md，服务清单在 mcp/README.md。
需要修改公共规则或公共 Skill 时，修改源文件，使用 tools/sync.ps1 预览差异；用户已授权同步时再用 -Apply。
客户端中 AgentKit 标记区域和分发的 agentkit-* Skill 是副本，不要直接修改。不要同步软件内置插件、会话数据库或凭据。
知识按任务需要读取，不要每次加载整库。Gety 只覆盖它实际索引的资料；搜索不到不能断言文件不存在。

## 共享待办

唯一待办文件是 D:/AgentKit/TODO.md，用于记录用户在各个会话中明确提出、需要稍后处理的事项；不是自动执行队列。所有 agent 直接维护同一文件，不创建客户端副本。
用户明确要求记待办、稍后处理，或要求查看和处理待办时，读取此文件并遵循其维护约定。先检查重复；更新前重新读取，只改相关条目。同一时刻由一个 agent 写入，已知存在并发编辑时先协调。
记录不等于授权执行。实际执行前遵循用户授权范围；完成后记录验证结果，不能将未完成事项标记完成。仅更新 TODO.md 无需运行同步脚本。
