## 记录约定

- **现场核验**：本机会话中有工具检查结果；注明时间和范围。
- **用户确认**：用户报告完成或使用正常；不扩写成所有功能均测试通过。
- **历史记录**：来自旧交接或较早检查；不能直接当作最新事实。
- **推断 / 待验证**：证据不足，不当作可删除依据。
- 数值优先保留字节；正文使用 GiB/MiB，分别按 1024³/1024² 换算。早期记录中写成 GB 的数字，多为这一换算口径，原文不改。
- 文件大小、磁盘实际占用、磁盘空闲空间净变化是三个概念，不强求相等。Junction、硬链接、压缩、权限以及后台写入都会影响统计。
- 记录不构成执行授权。用户说先检查、先讨论或暂缓时，不进行删除或迁移。
