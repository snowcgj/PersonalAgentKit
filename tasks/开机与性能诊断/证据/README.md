## 时间与数值口径

- 时间戳为本地时间（时区 Asia/Shanghai，偏差 -480 分钟），未经二次换算。
- 容量数值优先保留字节；正文使用 GiB/MiB 口径（分别按 1024³/1024² 换算）。早期别处档案写成 GB 的数字多为此口径，本档案不改写外部文件。
- 文件大小、磁盘占用、空闲空间净变化是三个概念，Junction、硬链接、压缩与后台写入都会影响统计，不强求相等。
